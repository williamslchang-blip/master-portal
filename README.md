## 🏛️ 總門戶簡介 (Overview)

本平台為 115 學年度全系列商管教學、實務財務個案與財務運算模型的整合性主控台（Master Portal）。透過直覺式的**按鍵與選單式三層級連動導航（Cascading Menus）**與**階層樹狀選單（Tree Accordion）**，全面整合每一週的互動教學簡報網頁（HTML）與教師授課指引手冊（Word .docx）。

## 💻 雙模運作機制 (Hybrid Online / Offline Engine)

Master Portal 配備智慧環境偵測器：
- **🌐 雲端連線版（GitHub Pages）**：直接透過網址開啟，自動解析並連動各子網站與 GitHub 資源。
- **💻 本機離線版（Local File / USB）**：複製整份資料夾至隨身碟或任何離線電腦，點開 `Master_Portal.html` 即可免連網順暢操作！
