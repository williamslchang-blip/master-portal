## 🎯 核心教學目標（回答兩大人生財務問題）
1. **退休時總共需要準備多少錢？**
   - 估計今日物價水準的生活開銷。
   - 考慮 40 餘年、每年 2% 通膨累積膨脹效果。
   - 應用 4% 安全提領法則（Bengen Trinity Study）估算退休目標資產規模。
2. **畢業開始工作後，每月應儲蓄或投資多少錢？**
   - 設定合理年化有效報酬率（預設 5%）。
   - 利用複利與年金終值反推每月應投入金額（PMT）。
   - 透過「投入本金 vs 複利收益」視覺化感受時間複利威力。
   - 檢驗大專畢業起薪（35,000 元）的可負擔性與現金流可行性。

## 🚀 六步驟活動功能特色

| 步驟 | 功能項目 | 核心教學點與公式 |
| :--- | :--- | :--- |
| **步驟一** | **設定退休基本條件** | 開始年齡（預設 22 歲）、退休年齡（預設 65 歲）、積累年數（43 年 / 516 個月）、現有儲蓄（PV）。 |
| **步驟二** | **估計生活費預算表** | 8 大支出項目（飲食、居住、水電、交通、醫療、保險、休閒、雜支），即時計算每月小計與每年小計，提供一鍵套用範本與支出圓餅圖。 |
| **步驟三** | **計算退休金總額** | 通膨調整公式：$退休時每月生活費 = 今日生活費 \times (1 + inf)^N$<br>4% 法則資產需求：$退休目標資產 = 退休年支出 \div 4\%$。 |
| **步驟四** | **反推每月儲蓄金額** | 有效月報酬率：$r = (1 + R)^{1/12} - 1$<br>年金終值反推：$PMT = \frac{FV - PV \times (1+r)^n}{[(1+r)^n - 1] / r}$<br>視覺化呈現資產累積 J 曲線與本金收益佔比甜甜圈圖。 |
| **步驟五** | **檢驗薪資可負擔性** | 畢業首任薪資（35,000元）扣除初入社會必要開銷（25,000元），動態評估退休儲蓄率與現金流缺口，提供紅黃綠健康燈號與破局解方。 |
| **步驟六** | **情境調整與反思** | 4 大經典情境直觀對比（基準、延後儲蓄至 30 歲、提早 55 歲退休、投資報酬率降至 3%），並以柱狀圖直觀呈現延遲與保守投資的代價。 |

## 📝 學生學習單（一頁紙實作繳交）
- **完整涵蓋課堂 5 大反思題目**：
  1. 預計退休年齡、每月生活費與支出最高前三項。
  2. 考慮通膨後的退休資產需求、公式與假設。
  3. 每月定期定額投入、累計本金與預估投資損益。
  4. 第一份工作薪資的可行性評估與現實分析。
  5. 無法達成目標時的優先調整順序與理由。
- **貼心互動功能**：
  - 🪄 **一鍵自動帶入數據**：自動抓取學生當前試算數值填入完整參考答案草稿。
  - 🖨️ **列印 / 另存為 PDF**：內建精緻 `@media print` 樣式，隱藏所有導航與按鈕，自動格式化為符合繳交規範的一頁式學習單。
  - 📋 **複製文字**：一鍵將作業文字格式化複製，方便貼入學校 LMS 或 Word。
  - 💾 **下載文字檔**：儲存個人填寫紀錄。
