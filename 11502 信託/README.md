## 文件架構與章節規劃

### 一、信託法規篇（第 1 ~ 8 章）
1. **第一章 信託概論與分類**（信託架構、自益/他益、私益/公益、金錢信託等）
2. **第二章 委託人、受託人、受益人**（各方權利義務、消極資格、受託人義務與責任）
3. **第三章 信託本旨、信託財產**（信託財產獨立性、追及權、不得強制執行原則）
4. **第四章 公益信託與信託監督**（公益信託設立許可、信託監察人、目的主管機關監督）
5. **第五章 信託業的設立與業務**（信託業法規範、設立資本額、營業範圍與禁止行為）
6. **第六章 信託業的管理與監督**（內部控制、內部稽核、財務比率、防制洗錢）
7. **第七章 基金與不指定集合管理運用**（共同信託基金、集合管理運用帳戶法規）
8. **第八章 各種稅務與法律責任**（所得稅、贈與稅、遺產稅、地價稅、土地增值稅及罰則）

### 二、信託實務篇（第 1 ~ 8 章）
1. **第一章 特定金錢信託總論**（受託投資國內外有價證券架構、流程與洗錢防制）
2. **第二章 特定金錢信託業務**（境內外基金投資實務、結構型商品、風險預告）
3. **第三章 企業員工持股信託**（員工持股會架構、自提與公司補助款、交付信託與贖回）
4. **第四章 有價證券信託**（有價證券借貸、表決權行使、股票信託節稅與傳承）
5. **第五章 不動產信託**（不動產開發信託、價金信託、安養信託與都市更新信託）
6. **第六章 金融資產證券化**（金融資產證券化特殊目的信託 SPT、不動產證券化 REITs/REATs）
7. **第七章 保管業務規定**（證券投資信託基金保管、全權委託投資保管實務）
8. **第八章 集合管理運用帳戶**（集合管理運用帳戶設置、會計處理與終止清算）
